Built on Next.js App Router (`app/` directory) with a strict layering: `app/**/page.tsx` routes compose feature pages that consume React hooks from `Hooks/` (e.g. `useAuth`, `useFarmer`, `useFields`, `useWeather`, `useMarket`, `useAssistant`). Each hook wraps a corresponding service in `services/` (e.g. `AuthAPI`, `FarmerAPI`, `FieldAPI`, `WeatherAPI`, `MarketAPI`, `AssistantAPI`) which centralizes `fetch` calls to the backend base URL (`NEXT_PUBLIC_API_BASE_URL`, default `http://localhost:8000`), handles token persistence in `localStorage`, request timeouts, and typed error classes. Global state is provided via React Contexts at the root layout: `AuthProvider` (wrapped around all children in `app/layout.tsx`) manages auth session with access/refresh token flow, and `LanguageProvider` (in `contexts/LanguageContext.tsx`) drives English/Urdu switching, RTL direction, and i18n lookups via `lib/translations`. Feature-specific UI lives under `components/<feature>/` (dashboard, market, weather, fields, farm, profile, cropDoctor, assistant, map, layout, ui), with shared primitives in `components/ui/`. Types are isolated in `types/` and consumed by both hooks and services. The app shell (`components/layout/AppShell`, `Sidebar`, `TopBar`) frames authenticated pages, while `components/auth/AuthGuard` gates route-level access.
