A single FastAPI instance in `main.py` is the sole process boundary: it configures CORS from `config/settings`, installs an HTTP timing middleware, then mounts each domain's router via `app.include_router`. Cross-cutting concerns are centralized — `config/supabase_client.py` exposes a singleton DB client, `dependencies/auth.py` provides the `get_current_user` dependency reused by all route modules, and `config/settings.py` loads `.env` values consumed everywhere. Each domain follows a consistent three-layer split (`routes/<domain>.py` → `services/<domain>_service.py` → `schemas/<domain>.py`) so new features are added by mirroring this layout and registering the router in `main.py`. The app exposes a `/health` endpoint and runs via uvicorn on port 8000 with reload enabled for development.
