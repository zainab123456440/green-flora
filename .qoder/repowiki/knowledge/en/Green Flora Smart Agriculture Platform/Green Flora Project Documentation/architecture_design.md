The docs module is a flat Markdown knowledge base organized by functional area: `System Architecture/` (backend services, external integrations including AMIS scraping and weather/AI providers, database design, data flow), `Frontend Application/` (Next.js App Router structure, feature modules like Dashboard/Farm Management/Crop Doctor/Market Analysis/Weather, plus API integration and state management), `Backend API Reference/` (per-route REST specs for assistant, auth, farmer, field, crop doctor, market, government support), `AI Integration/` (OpenAI Assistant, Gemini, tool-calling orchestration), and cross-cutting guides (`Configuration and Deployment`, `Data Models and Database Schema`, `Testing Strategy`, `Security Considerations`, `Troubleshooting Guide`). Each document follows a consistent template with Table of Contents, Mermaid diagrams, section sources referencing concrete source files in `Backend/`, `Frontend/greenflora/`, and project-level context files. Dependency direction is one-way: documents describe code but contain no executable logic; they link to source files via relative paths and `<cite>` blocks that enumerate referenced implementation files.
