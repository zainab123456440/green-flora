The `main.py` entrypoint instantiates one FastAPI app, registers CORS and an HTTP timing middleware, then mounts each domain's router (`farmer`, `auth`, `field`, `crop_doctor`, `market`, `support`, `assistant`) via `app.include_router`. Cross-cutting concerns are centralized in `config/` (settings loaded from `.env`, shared Supabase client) and `dependencies/auth.py` (shared auth dependency injected by routes). Each domain follows the same three-layer split — `routes/<domain>.py` → `services/<domain>_service.py` → `schemas/<domain>.py` — so new domains are added by mirroring this layout and including the router in `main.py`. The app exposes a `/health` endpoint and runs via uvicorn on port 8000 with reload enabled for development.
