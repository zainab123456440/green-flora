The repository orchestrates three cooperating services with Supabase PostgreSQL as the single source of truth. The frontend (Next.js/React) communicates with the backend via HTTPS REST and SSE; the backend (FastAPI) aggregates weather (Open-Meteo), market data, agricultural products, and an AI assistant (OpenAI GPT-5.6 Luna with Gemini Flash fallback) while persisting all application state in Supabase. A separate GitHub Actions–triggered Python scraper pipeline (`amis-scraper.yml`, running daily at 06:00 UTC) ingests AMIS Pakistan wholesale prices into the same tables so the Market page, Dashboard, and AI Assistant consume identical normalized records without duplicating data. Secrets (OpenAI, Gemini, Supabase keys) are injected only on the backend and the CI runner — the frontend never holds API credentials — keeping data ingestion decoupled from web-server uptime.
